
# 🎓 Student Expense Tracker

A clean, responsive, and beginner-friendly expense tracker built with pure HTML, CSS, and Vanilla JavaScript. Designed specifically for college students to track their daily pocket money and expenses by category.

## 🚀 Features

- **Add Expenses:** Log title, cost in rupees (₹), date, and category.
- **Student Categories:** Dedicated color-coded tags for *Food*, *Travel*, *Books*, *Fun*, and *Other*.
- **Category Spending Breakdown:** Displays running totals spent across each category.
- **Filter Expenses:** Filter the list to inspect spending by a specific category.
- **Live Calculations:** Automatically calculates the grand total when items are added or removed.
- **Persistent Storage:** Uses browser `localStorage` so data stays saved across reloads and tab closes.
- **Mobile Responsive:** Clean, centered card design optimized for both desktop and mobile screens.

## 🛠️ Technologies Used

- **HTML5:** Semantic layout and accessible form controls.
- **CSS3:** Custom styles, CSS variables, Flexbox, and responsive media queries.
- **JavaScript (ES6):** DOM manipulation, array methods (`filter`, `reduce`), and Web Storage API (`localStorage`).
